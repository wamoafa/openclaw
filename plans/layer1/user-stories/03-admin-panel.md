# User Stories — Admin Panel

## الشخصيات

| الشخصية | الوصف |
|---------|-------|
| **أحمد** | مسؤول تقني، يريد رؤية كاملة للنظام |
| **نورة** | مسؤولة عمليات، تريد تتبع الإيرادات وإدارة المستخدمين |

---

## Overview

### US-A-001 | لوحة المسؤول الرئيسية

**بوصفي** مسؤولاً,
**أريد** أن أرى نظرة عامة على النظام فور دخولي,
**حتى** أعرف الصحة العامة فوراً.

**معايير القبول:**
- [ ] KPIs رئيسية: مستخدمون نشطون، instances تشتغل، رسائل/يوم، إيراد الشهر
- [ ] رسم بياني: نمو المستخدمين آخر 30 يوم
- [ ] تنبيهات نظام فعّالة (instances متوقفة، أخطاء API)
- [ ] آخر 10 مستخدمين سجّلوا

**الحجم:** L
**الأولوية:** P0

---

## User Management

### US-A-002 | عرض قائمة المستخدمين

**بوصفي** مسؤولاً,
**أريد** أن أرى كل المستخدمين مع تفاصيلهم,
**حتى** أديرهم بكفاءة.

**معايير القبول:**
- [ ] جدول: الاسم، البريد، الخطة، تاريخ التسجيل، الحالة
- [ ] فلتر حسب: الخطة، الحالة، تاريخ التسجيل
- [ ] بحث بالاسم أو البريد
- [ ] ترقيم صفحات (50 مستخدم/صفحة)
- [ ] تصدير CSV

**الحجم:** M
**الأولوية:** P0

---

### US-A-003 | تفاصيل مستخدم

**بوصفي** مسؤولاً,
**أريد** رؤية كل تفاصيل مستخدم معين,
**حتى** أفهم سلوكه وأساعده أو أتخذ إجراءً.

**معايير القبول:**
- [ ] معلومات الحساب: الاسم، البريد، تاريخ التسجيل، الخطة
- [ ] instances المرتبطة مع حالتها
- [ ] القنوات المرتبطة
- [ ] إحصائيات الاستخدام (رسائل/شهر)
- [ ] سجل الفواتير
- [ ] سجل نشاط الحساب (login history)

**الحجم:** L
**الأولوية:** P0

---

### US-A-004 | تعديل حالة المستخدم

**بوصفي** مسؤولاً,
**أريد** أن أتحكم في حساب المستخدم,
**حتى** أتعامل مع انتهاكات أو مشاكل.

**معايير القبول:**
- [ ] تعليق الحساب مع سبب
- [ ] إلغاء التعليق
- [ ] تغيير الخطة يدوياً (ترقية/تخفيض)
- [ ] منح فترة تجريبية ممتدة
- [ ] إرسال بريد إلى المستخدم مباشرة من الداشبورد
- [ ] كل إجراء يُسجّل في audit log

**الحجم:** L
**الأولوية:** P1

---

### US-A-005 | حذف مستخدم

**بوصفي** مسؤولاً,
**أريد** حذف حساب مستخدم نهائياً,
**حتى** أتوافق مع طلبات GDPR أو انتهاكات الشروط.

**معايير القبول:**
- [ ] dialog تأكيد يذكر كل ما سيُحذف
- [ ] خيار: حذف الـ instances أيضاً أم لا
- [ ] يُسجّل في audit log مع هوية المسؤول
- [ ] يُرسل بريد للمستخدم بتأكيد الحذف

**الحجم:** M
**الأولوية:** P1

## Instance Management (Admin View)

### US-A-006 | عرض كل الـ Instances

**بوصفي** مسؤولاً,
**أريد** رؤية كل الـ instances في النظام,
**حتى** أراقب الموارد وأكتشف المشاكل.

**معايير القبول:**
- [ ] جدول: المعرّف، المالك، المنطقة، الحالة، تاريخ الإنشاء
- [ ] فلتر حسب: الحالة، المنطقة، المالك
- [ ] مؤشر استخدام CPU/RAM لكل instance
- [ ] إجمالي instances نشطة في الأعلى

**الحجم:** M
**الأولوية:** P1

---

### US-A-007 | إيقاف/إعادة تشغيل Instance

**بوصفي** مسؤولاً,
**أريد** التحكم في أي instance,
**حتى** أحل مشكلة أو أوفّر موارد.

**معايير القبول:**
- [ ] إيقاف instance مع سبب
- [ ] إعادة تشغيل instance
- [ ] إشعار للمالك عند الإيقاف الإداري
- [ ] يُسجّل في audit log

## Billing & Revenue

### US-A-008 | لوحة الإيرادات

**بوصفي** نورةً (مسؤولة عمليات),
**أريد** رؤية إيرادات الشهر وتوجهاتها,
**حتى** أتتبع نمو الأعمال.

**معايير القبول:**
- [ ] MRR (Monthly Recurring Revenue) الشهر الحالي
- [ ] مقارنة بالشهر السابق (نسبة النمو)
- [ ] توزيع الإيرادات حسب الخطة (Free/Pro/Team)
- [ ] رسم بياني: MRR آخر 12 شهر
- [ ] عدد الإلغاءات هذا الشهر
- [ ] Churn Rate

**الحجم:** L
**الأولوية:** P1

---

### US-A-009 | عرض الفواتير

**بوصفي** مسؤولاً,
**أريد** رؤية كل الفواتير,
**حتى** أحل نزاعات أو أتحقق من مدفوعات.

**معايير القبول:**
- [ ] قائمة فواتير: المستخدم، المبلغ، التاريخ، الحالة
- [ ] فلتر حسب: الحالة (مدفوع/معلق/مسترد)، الفترة الزمنية
- [ ] رابط لفاتورة Stripe لكل صف
- [ ] إمكانية إصدار استرداد يدوي

**الحجم:** M
**الأولوية:** P1

## System Health

### US-A-010 | مراقبة صحة النظام

**بوصفي** أحمدًا (مسؤول تقني),
**أريد** مراقبة صحة Layer 2 والـ infrastructure,
**حتى** أكتشف المشاكل قبل أن تؤثر على المستخدمين.

**معايير القبول:**
- [ ] حالة Core API (latency، error rate)
- [ ] حالة Broker → VPS connectivity
- [ ] قائمة الأخطاء الأخيرة مع تفاصيل
- [ ] uptime percentage آخر 30 يوم
- [ ] تنبيه لو error rate تجاوز حداً معيناً

**الحجم:** L
**الأولوية:** P1

## Announcements

### US-A-011 | إرسال إعلان للمستخدمين

**بوصفي** مسؤولاً,
**أريد** إرسال إعلان لمجموعة من المستخدمين,
**حتى** أخبرهم بتحديثات أو صيانة.

**معايير القبول:**
- [ ] فورم: العنوان، المحتوى (Markdown)، الاستهداف (كل المستخدمين / خطة معينة)
- [ ] معاينة الإعلان قبل الإرسال
- [ ] خيار: إرسال بريد + إشعار في الداشبورد
- [ ] جدولة الإرسال (مستقبل)
- [ ] عرض الإعلانات السابقة مع إحصائيات القراءة

**الحجم:** L
**الأولوية:** P2

## Audit & Security

### US-A-012 | Audit Log

**بوصفي** مسؤولاً,
**أريد** رؤية سجل كل الإجراءات الإدارية,
**حتى** أضمن المساءلة والأمان.

**معايير القبول:**
- [ ] كل إجراء مسجّل: من، ماذا، على من، متى
- [ ] بحث وفلترة بالتاريخ والنوع والمسؤول
- [ ] لا يمكن حذف أو تعديل سجلات الـ audit log
- [ ] تصدير CSV

**الحجم:** M
**الأولوية:** P1

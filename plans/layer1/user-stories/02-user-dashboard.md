# User Stories — User Dashboard

| الشخصية | الوصف |
|---------|-------|
| **زياد** | غير تقني، يريد يشغّل المساعد على واتساب بدون تعقيد |

## Onboarding Flow (أول دخول)

### US-D-001 | Onboarding خطوة بخطوة

**بوصفي** مستخدمًا جديدًا دخلت Dashboard لأول مرة,
**أريد** أن يرشدني النظام خطوة بخطوة,
**حتى** أصل لأول محادثة مع المساعد بسرعة.

**معايير القبول:**
- [ ] Progress bar يوضح مكاني في الـ onboarding (خطوة 1/4 مثلاً)
- [ ] الخطوات: إنشاء instance → ربط قناة → اختبار المساعد → اكتمال
- [ ] كل خطوة لها شرح بلغة بسيطة
- [ ] تقدر تتخطى وترجع لاحقاً
- [ ] عند الاكتمال: celebration screen + رابط للداشبورد الرئيسي

**الحجم:** XL
**الأولوية:** P0

## Overview / Home

### US-D-002 | نظرة عامة سريعة

**بوصفي** مستخدمًا نشطًا,
**أريد** أن أرى حالة كل شيء في صفحة واحدة,
**حتى** أعرف فوراً إذا في مشكلة أو كل شيء يعمل.

**معايير القبول:**
- [ ] بطاقة لكل instance نشط مع: الاسم، الحالة (🟢/🔴/🟡)، القنوات المرتبطة
- [ ] عدد الرسائل الواردة اليوم
- [ ] تنبيهات فعّالة (instance متوقف، قناة مفصولة)
- [ ] رابط سريع لإجراء الأكثر استخداماً

**الحجم:** M
**الأولوية:** P0

## Instance Management

### US-D-003 | عرض قائمة الـ Instances

**بوصفي** مستخدمًا,
**أريد** أن أرى كل الـ instances الخاصة بي,
**حتى** أديرها من مكان واحد.

**معايير القبول:**
- [ ] جدول/بطاقات: الاسم، المنطقة، الحالة، تاريخ الإنشاء
- [ ] فلتر حسب الحالة (نشط/موقوف)
- [ ] زر "إنشاء instance جديد" واضح
- [ ] عرض الـ instance المجاني (إن وجد) منفصلاً

**الحجم:** M
**الأولوية:** P0

---

### US-D-004 | إنشاء Instance جديد

**بوصفي** مستخدمًا,
**أريد** إنشاء agent instance جديد بخطوات بسيطة,
**حتى** أبدأ استخدام المساعد على قناة جديدة.

**معايير القبول:**
- [ ] اختيار اسم للـ instance (مع اقتراح تلقائي)
- [ ] اختيار المنطقة الجغرافية (مع تأثير Latency واضح)
- [ ] اختيار الخطة (إذا لم يكن مشتركاً)
- [ ] شريط تقدم إنشاء الـ instance (مع وقت تقديري)
- [ ] إشعار عند الاكتمال + انتقال تلقائي لصفحة Instance
- [ ] رسالة واضحة لو وصل لحد الخطة

**الحجم:** XL
**الأولوية:** P0

---

### US-D-005 | تفاصيل Instance

**بوصفي** مستخدمًا,
**أريد** أن أرى تفاصيل instance معين,
**حتى** أديره أو أحل مشكلة فيه.

**معايير القبول:**
- [ ] الحالة الكاملة (uptime، آخر نشاط)
- [ ] القنوات المرتبطة مع حالة كل قناة
- [ ] أزرار: إيقاف مؤقت / إعادة تشغيل / حذف
- [ ] Logs آخر 50 سطر مع زر "تحديث"
- [ ] إعدادات الـ agent (نموذج AI المستخدم، المزود)

**الحجم:** L
**الأولوية:** P0

---

### US-D-006 | حذف Instance

**بوصفي** مستخدمًا,
**أريد** حذف instance لا أحتاجه,
**حتى** لا أدفع عليه.

**معايير القبول:**
- [ ] dialog تأكيد واضح مع اسم الـ instance
- [ ] تحذير: "سيُحذف كل البيانات المرتبطة"
- [ ] يجب كتابة اسم الـ instance لتأكيد الحذف
- [ ] إشعار نجاح بعد الحذف

**الحجم:** S
**الأولوية:** P1

## Channel Management

### US-D-007 | ربط قناة واتساب

**بوصفي** زيادًا,
**أريد** ربط رقم واتساب الخاص بي بالمساعد,
**حتى** يرد على رسائلي هناك.

**معايير القبول:**
- [ ] عرض QR code مع تعليمات واضحة (صور خطوة بخطوة)
- [ ] مؤقت: QR يتجدد كل 60 ثانية
- [ ] حالة الاتصال تتحدث فورياً (WebSocket)
- [ ] رسالة نجاح مع تعليمات للاختبار

**الحجم:** L
**الأولوية:** P0

---

### US-D-008 | ربط قناة Telegram

**بوصفي** مستخدمًا,
**أريد** ربط Telegram bot بالمساعد,
**حتى** أستخدمه عبر Telegram.

**معايير القبول:**
- [ ] حقل لـ Bot Token مع رابط لكيفية الحصول عليه من @BotFather
- [ ] تحقق فوري من صحة الـ token
- [ ] عرض اسم الـ bot بعد الربط الناجح
- [ ] تعليمات اختبار: "أرسل /start للبوت"

**الحجم:** M
**الأولوية:** P0

---

### US-D-009 | إدارة القنوات المرتبطة

**بوصفي** مستخدمًا,
**أريد** رؤية وإدارة كل القنوات المرتبطة,
**حتى** أفصل أو أعيد ربط أي قناة.

**معايير القبول:**
- [ ] قائمة القنوات مع: الأيقونة، الاسم، الحالة، تاريخ الربط
- [ ] زر "فصل" مع dialog تأكيد
- [ ] زر "إعادة ربط" للقناة المفصولة
- [ ] badge تنبيه للقنوات ذات مشاكل

**الحجم:** M
**الأولوية:** P1

## Usage & Billing

### US-D-010 | عرض الاستخدام

**بوصفي** مستخدمًا,
**أريد** أن أرى كم استخدمت من حصتي,
**حتى** لا أفاجأ بتجاوز الحد.

**معايير القبول:**
- [ ] شريط تقدم: الرسائل المستخدمة / الحد الكلي
- [ ] رسم بياني بسيط: استخدام آخر 30 يوم
- [ ] تاريخ تجديد الحصة
- [ ] تنبيه عند الوصول لـ 80% من الحصة
- [ ] زر ترقية الخطة (إن كان على خطة مجانية)

**الحجم:** M
**الأولوية:** P1

---

### US-D-011 | إدارة الاشتراك

**بوصفي** مستخدمًا مشتركًا,
**أريد** رؤية تفاصيل اشتراكي وتغييره,
**حتى** أتحكم في تكاليفي.

**معايير القبول:**
- [ ] عرض الخطة الحالية + تاريخ التجديد + السعر
- [ ] تاريخ الفواتير السابقة مع رابط تحميل PDF
- [ ] زر "ترقية الخطة" مع مقارنة
- [ ] زر "إلغاء الاشتراك" مع شرح ما سيحدث
- [ ] إدارة طريقة الدفع (Stripe Customer Portal)

**الحجم:** L
**الأولوية:** P1
